Placeholder for pheromone evaporation, deposit and clamping behavior, executed once per iteration of the ACO algorithm.

  • optimizer – ACO optimizer executing the current iteration

  • iteration_best_solution (Solution) – best solution found in the current iteration

  • global_best_solution (Solution) – best solution found so far, across all iterations
